# Wholeness and Perfection

Static edition, including the latest UI changes.

## GitHub Pages

Upload this directory's contents to the root of your repository. In Settings → Pages, choose Deploy from a branch, then main and / (root). GitHub will display the published URL when deployment succeeds.

Open the site in a browser; no ChatGPT account is needed. Demo mode works without hardware. To use the physical wheel, connect Arduino to the viewing computer and select the serial port in Chrome or Edge. Use 9600 baud and close Arduino Serial Monitor first.

One full turn advances two frames. Reset clears progress and stays on the experience; Home returns to the landing page.
